# Security policy

## Reporting a vulnerability

Report it privately through GitHub: open the
[Security tab](https://github.com/namaserajesh/ai-job-search-india/security) and
click **Report a vulnerability**. Please do not open a public issue for a
security problem.

| Stage | Target |
|---|---|
| Acknowledgement | within 72 hours |
| Initial assessment | within 7 days |

Include the version or commit, what an attacker could do, and the steps to
reproduce it.

A problem in career-ops itself belongs with that project: see its
[security policy](https://github.com/career-ops-hq/career-ops/security/policy).

## Supported versions

The latest release is supported. Fixes land on `main` and ship in the next
release.
